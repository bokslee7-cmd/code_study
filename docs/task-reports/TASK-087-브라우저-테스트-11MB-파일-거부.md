## 작업 요약
11MB .py 파일을 선택하고 제출해 거부되는지, 에러 메시지가 보이는지 확인했다.

## 변경 파일

- `specs/001-ai-code-learning-platform/tasks.md` (T087 완료 표시)

## TDD 결과
- 해당 없음(수동 브라우저 테스트). 결과: **통과**
- 메시지: '파일 업로드 실패: 파일 크기가 10MB를 초과합니다. 더 작은 파일을 선택하거나 코드를 여러 태스크로 나누어 업로드하세요.' 서버로 요청이 가지 않았다(클라이언트에서 차단). 태스크는 만들어지지 않았다.

## 기술 결정
- 실행 환경: Docker(PostgreSQL 15, Redis 7) + uvicorn(8000) + Vite(5173), Chromium headless, Playwright 1.49.1. 세션에 Playwright MCP 도구가 연결되지 않아 스크래치 폴더에 Playwright를 따로 설치해 같은 엔진으로 스크립트를 실행했다(프로젝트에는 설치하지 않음).
- 테스트 계정은 실행마다 새 이메일로 회원가입해 만들었다.

## 비고
- **UX 이슈(미수정)**: 같은 화면에 두 메시지가 동시에 뜬다. 파일 선택 시점의 '10MB 초과' 메시지와, 파일이 목록에 추가되지 않은 채 제출했을 때의 '업로드할 파일을 한 개 이상 선택하세요.'다. 후자는 사실이지만 사용자에게는 모순처럼 보일 수 있다. 스크립트가 거부된 파일을 선택한 직후 곧바로 제출해서 생긴 상황이라 실제 사용에서는 덜 나타날 수 있다.
