## 비고
- 같은 세션 시작 시 PostgreSQL이 없어 skip이던 통합 테스트 4개를 이번에 실제 DB로 실행했다. 2개가 실패했고 원인은 테스트 코드(`session.expire_all()` 뒤에 `task.id` 지연 로딩 → MissingGreenlet)였다. 운영 코드는 `expire_on_commit=False`라 영향이 없다. 테스트가 id를 미리 변수에 담도록 고쳐 4/4 통과했다(변경: backend/tests/integration/test_task_service_integration.py). 이로써 번호 부여·행 잠금·업로드 왕복이 실제 DB에서 검증됐다.
- 동시 요청 시나리오(여러 탭에서 동시에 생성)는 브라우저로 시험하지 않았다.
